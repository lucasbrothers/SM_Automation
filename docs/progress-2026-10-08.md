# 2026-10-08 개발 기록

## 결정

Linux 메인 서버가 모든 실제 업무를 담당한다. Windows는 네이티브 GUI/통제만 담당한다.
Windows ↔ Linux는 전용 TLS/TCP 7443이며 SSH 터널·웹 UI를 사용하지 않는다.
대상 서버 접속은 SSH를 유지한다. PostgreSQL은 제거한다.
마감은 사용자 후속 지시로 한국 시간 18시에서 19시로 변경되었다.

## 구현

1. Linux 서비스, 전용 TLS 메시지 프로토콜, 접근 토큰 인증과 GUI 클라이언트.
2. 별도 키를 쓰는 Fernet 암호화 저장, DATA/BACKUP 경로 설정, 원자적 저장.
3. 암호화 인벤토리 및 비동기 작업 이력, 재시작 시 미완료 작업 표시.
4. netstat ESTABLISHED 수집, 체크박스·전체선택, 검색·확대/이동 가능한 마인드맵.
5. Linux/AIX/Windows 주요 파일과 명령 결과 백업, sudoers/sudoers.d 및 계정별 만료/권한 정보.
6. Windows GUI의 Overview, Connection map, Backups, Activity와 결과 조회.
7. Linux에만 존재하는 SSH 접속 프로필; GUI는 프로필 이름만 지정.
8. Linux 프로비저닝, systemd 템플릿, 오프라인 패키지 준비, 암호화 백업 내보내기 도구.
9. PostgreSQL 모듈·스키마·의존성·설치 스크립트 제거. 실제 DB 삭제나 OS 서비스 제거는 하지 않음.
10. README·설정·설치·백업·다른 PC 인계 문서 및 실제 GUI 코드로 렌더링한 목업.

## 확인 범위

사용자 지시대로 pytest, Linux 서버 실행, TLS 실연결, SSH 실접속, 백업·복원 테스트는
실행하지 않았다. Python 구문 파싱과 GUI 데모의 화면 렌더링만 확인했다.
목업은 문서용 가상 주소를 쓰는 예시 데이터이며 운영 성공 증거가 아니다.
새 기능은 다음 PC에서 기능 단위로 확인한다. 상세 인계는 pc-handoff.md에 있다.

## 남은 범위

OS별 실환경 명령/권한/인코딩 조정, 사용자별 권한, 취소/예약 작업, 대규모 백업 스트리밍,
복원 자동화, 계정·패치 관리 GUI, 전체 보안 정책 적용 GUI는 후속 작업이다.
현재 GUI의 데이터는 메모리에서만 표시하며 운영 데이터 저장은 Linux에서 수행한다.
