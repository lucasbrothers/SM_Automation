# 보안 기능 아키텍처

2026-10-08 현재 배포 모델은 [architecture.md](architecture.md)를 따른다.
Linux 메인 서버에서만 대상 SSH와 보안 작업을 수행하며 Windows는 전용 TLS 포트 GUI다.
DB는 없고 작업 결과는 DATA에 암호화 저장한다.

기존 보안 정책 파일과 Linux 감사·평가·조치 계획·SSH 설정 적용 모듈은 유지했다.
새 GUI는 Overview의 Security audit를 통해 Linux의 읽기 전용 기본 감사를 요청한다.
GUI에서 정책 적용/계정 변경을 실행하는 기능은 아직 연결하지 않았다.

| 구성 | 현재 상태 |
| --- | --- |
| RHEL 8/9, AIX 7.1, Windows 2022 정책 JSON | 유지 |
| Linux SSH 기본 보안 감사 | Linux 작업 큐 및 GUI에서 요청 가능 |
| 기존 정책 평가/조치 계획 | 모듈 유지, GUI 편집/적용 화면은 후속 |
| 기존 Linux SSH 설정 적용/복구 | 모듈 유지; 이번 개발에서는 실행 안 함 |
| AIX/Windows 전체 보안 정책 평가 | 후속 구현 |
| PostgreSQL 보안·CMDB | 제거 |

보안 정책 파일은 운영 기준 초안이며 실제 고객사 기준/OS와 대조해야 한다.
검증 절차를 확대하지 않는다는 요청은 이번 개발의 테스트 범위에 반영했다.
인증서 확인, 암호화, 대상 경로 제한 및 기존 원격 설정 변경의 복구 장치는 유지한다.
기존 CLI는 과거 호환 도구이고 평문 파일 입출력을 포함하므로 새 GUI 운영 경로로 쓰지 않는다.
